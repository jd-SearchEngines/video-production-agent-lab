# Limitations

- v0.1 is a text-card animatic, not a human-reviewed finished edit.
- There is no narration, music, image generation, provider routing, or external research.
- v0.2 is a deterministic failure-locality simulation, not a latency benchmark.
- v0.3 uses a scripted local model boundary and no real LLM; all model and cost fields are null.
- ffprobe validity is not the same as semantic or aesthetic video quality.
- The implementation has no checkpoint/resume, repair, human approval, or production sandbox.
