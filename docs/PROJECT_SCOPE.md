# Project Scope

## First-round boundary

This repository executes v0.1, v0.2, and v0.3 only. The first round must establish real local evidence before expanding the architecture.

In scope:

- local text-card MP4 production with FFmpeg;
- formal JSON artifact envelopes;
- a YAML stage manifest and failure-locality comparison;
- independent stage-director skills and a deterministic comparison;
- bad-case preservation, reports, tests, and GitHub provenance.

Out of scope until a later gated version: provider routing, fallback states, checkpoint/resume, video QA and repair, cost governance, human approval, multi-agent execution, model training, and paid APIs.
