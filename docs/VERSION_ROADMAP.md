# Version Roadmap

| Version | Question | Gate |
|---|---|---|
| v0.1 | Can a local agent produce a playable MP4? | real file, probe metrics, bad case |
| v0.2 | Does a formal pipeline improve failure locality? | same fixtures, ad-hoc comparison |
| v0.3 | Do stage skills improve artifact quality? | six-fixture deterministic comparison |
| v0.4 | Can the agent route capabilities to providers? | not started |
| v0.5 | Can an interrupted run resume locally? | not started |
| v0.6 | Can the agent verify and repair video output? | not started |
| v0.7 | Can quality, cost, and latency guide decisions? | not started |
| v1.0 | Can the complete production loop be audited and approved? | not started |

No later version should be marked complete without a new real run and retained evidence.
